# RatioLabs

**Research, applications, and games**

RatioLabs researches artificial intelligence, cryptography, and quantum computing, and develops applications and games.

[ratiolabs.eu](https://www.ratiolabs.eu) · [Medium](https://medium.com/@ratiolabsEU) · [info@ratiolabs.eu](mailto:info@ratiolabs.eu)

---

## Research

- **Topics:** Artificial intelligence, cybersecurity, post-quantum cryptography, and quantum computing.
- **Methods:** Reproducible experiments on our own tools and benchmarks, with stated assumptions and limits.
- **Open publication:** Results, data, and code are published openly for review and reproduction.

## Applications & Games

- **Privacy by design:** Full respect for the user. No accounts, no cookies, no tracking, no advertising. Data stays on the device; optional sync between devices is end-to-end encrypted. AI requests are not stored or used to train models. Payments are processed by an external Merchant of Record.
- **Open source:** The code that handles user data is released under the Apache 2.0 license. Every privacy commitment can be audited.
- **Proprietary assets:** The core of each application is our own: computational engines built on established scientific methods, and original artistic work.
- **Technology:** Browser-based applications (PWA) that run locally and install on any device.
